
🦷 Técnica Dental - Tarjetas Publicitarias Personalizables
Aplicación web para generar tarjetas publicitarias personalizadas para laboratorios y clínicas dentales.

Permite editar información, imágenes y elementos visuales para crear material promocional de forma rápida y sencilla.

✨ Características
✅ Edición del nombre del laboratorio.
✅ Personalización de teléfono y datos de contacto.
✅ Cambio de imágenes y logotipos.
✅ Diseño adaptable y fácil de utilizar.
✅ Generación de publicidad lista para compartir.
✅ Interfaz simple basada en HTML, CSS y JavaScript.
🚀 Tecnologías utilizadas
HTML5
CSS3
JavaScript
