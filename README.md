🦷 Técnica Dental - Tarjetas Publicitarias Personalizables
Aplicación web para generar tarjetas publicitarias personalizadas para laboratorios y clínicas dentales. Permite editar información, imágenes y elementos visuales para crear material promocional de forma rápida y sencilla.

✨ Características
Edición de nombre del laboratorio.
Personalización de teléfono y datos de contacto.

Diseño adaptable y fácil de utilizar.
